# Projet-CGroupB



Description du projet :
Ce projet a pour but la gestion d’un réseau de parking avec l’utilisation d’un fichier csv, 

Par le biais de plusieurs fonctions permettant la gestion des entrer sortie et l’actualisations dans les données des parkings, il a été réalisé sur visual studio code  

Technologies: C (standard + Windows.h pour Sleep), CSV,Visual studio Code 


guide instllations prérequis:

Prérequis : Compilateur C (type GCC, MinGW)
